# Project Governance

## Project Classification

Mettelo Project Studio — simulated confidential-client engagement.

## Client Representation

The confidential client is simulated.

Participants must not claim:

- employment by the simulated client;
- access to a real confidential regulatory authority;
- that FSA open data is private Mettelo client data;
- that Mettelo has an undisclosed external client relationship represented by this project.

Participants may accurately describe verified participation in Mettelo Project Studio.

## Data Source

The underlying data is official Food Standards Agency open data covering food hygiene ratings.

Teams must retain source attribution and follow the applicable reuse terms.

## Responsible Analytics

Teams must:

- avoid presenting a food hygiene rating as a complete current risk assessment;
- distinguish historical rating status from current confirmed conditions;
- document inspection-age limitations;
- account for scheme differences;
- avoid unsupported causal claims;
- avoid misleading comparisons driven only by establishment volume;
- treat prioritisation flags as analytical indicators, not enforcement decisions.

## GitHub Security

Never commit:
- passwords;
- tokens;
- API keys;
- private credentials;
- personal information not intended for publication.

## Verification

Mettelo may review commits, issues, pull requests, reviews, documentation, analytical artefacts and presentation evidence to verify participation and contribution.
